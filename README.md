# 이종족연합국 그린스토아

정적 HTML로 만든 도트풍 타이틀·프롤로그·초반 여정입니다. `index.html`에 배경 이미지,
스타일, 동작 코드가 모두 포함되어 있어 별도 설치나 빌드 없이 열 수 있습니다.

로컬 서버로 확인하려면 저장소에서 `python3 -m http.server 8000`을 실행하세요.

`CSS/main.css`, `CSS/game.css`, `JS/main.js`, `JS/story.js`, `JS/game.js`,
`JS/events.js`, `JS/audio.js`, 이미지를 수정한 뒤에는
`python3 scripts/build-standalone.py`를 실행해 `index.html`에 반영하세요.
문구와 화면 구조는 `templates/index.html`에서 수정한 다음 같은 명령으로
단일 파일을 생성합니다. 생성된 `index.html`에는 폰트까지 모두 포함됩니다.

UI에는 Galmuri 2.40.3 한글 픽셀 폰트를 사용합니다. 라이선스는
`assets/fonts/LICENSE.txt`와 생성 HTML에 포함되어 있습니다.

캐릭터는 `assets/greenstoa-elf-idle.png` 왼쪽 원화를 고정된 기준으로
사용합니다. 원화를 기준으로 머리카락·망토·호흡 포즈를 고정된 도트
프레임으로 미리 만든 뒤 10fps로 교체합니다. 눈은 열림·반쯤 감김·감김의
세 단계로 표시하며 색상을 페이드하지 않습니다. 오른쪽 원화는 눈을 감는
작은 영역에만 사용하고 얼굴 전체를 교체하지 않습니다.
6.4초 주기가 같은 원화로 이어집니다.
어깨와 상체에는 3.2초 주기의 작은 호흡 움직임을 적용합니다. 원화 기준
최대 2픽셀만 올라가며 얼굴과 하체 쪽으로 갈수록 움직임이 줄어듭니다.
옵션이나 시스템의 움직임 감소 설정으로 정지할 수 있습니다.

캐릭터의 보이는 부분을 클릭하면 클릭한 위치에 사각 말풍선이 열립니다.
다시 클릭하거나 말풍선의 다음 버튼을 누르면 8개의 임시 대사를 순서대로
보여줍니다. 대사는 `JS/main.js`의 `dialogues`에서 수정할 수 있습니다.
캐릭터에 키보드 초점을 두고 Enter 또는 Space로 대화할 수도 있습니다.
말풍선은 닫기 버튼, Escape 또는 바깥 클릭으로 닫습니다.

마우스 커서는 `assets/cursors/`의 32px 픽셀 만년필이며 펜촉이 클릭
위치입니다. 버튼 위에서는 작은 빛 표시가 붙고 버튼이 살짝 떠오릅니다.
클릭할 때는 클릭 위치에서 밝은 도트가 퍼지며 버튼은 짧게 눌렸다 튀어
오릅니다. 효과는 설정 창 위에도 표시되며 터치와 키보드 버튼 조작도
지원합니다. 화면 움직임을 끄거나 시스템의 움직임 감소를 설정하면
추가 애니메이션도 정지합니다. 커서 SVG 역시 단일 HTML에 포함됩니다.

시작하기를 누르면 아홉 장면의 양피지 프롤로그가 이어집니다.
내레이션과 삽화 배치는 `JS/story.js`의 `scenes`에서, 그림은
`assets/greenstoa-prologue.png`의 2열×3행 가로 삽화 시트에서 관리합니다.
각 장면의 `panel` 값으로 여섯 삽화 중 하나를 골라, 그림을 늘리거나 자르지 않고
엘프의 탄생·건국·이종족의 이주·용사 제르와 동맹·현재의 조사 의뢰까지 설명합니다.
검은 여백 가운데 가로 삽화를 배치하고 바로 아래에 내레이션이
한 글자씩 나타납니다. 삽화는 원본의 9:4 비율과 전체 구도를 유지하며,
화면에 맞춰 같은 배율로 축소합니다. 쉼표와 문장 끝에서 잠시 쉬며, 줄바꿈 위치는
타이핑 중에도 고정됩니다. 다음 버튼을 한 번 누르면 문장 전체를 보이고,
한 번 더 누르면 다음 장면으로 넘어갑니다. 자동 넘김은 타이핑이 끝난
후 읽을 시간을 두고 진행되며 끌 수도 있습니다. 건너뛰기는 이름
입력으로 연결됩니다. 화면 움직임 감소 설정에서는 페이드와 타이핑을
생략하고 문장 전체를 표시합니다.

오프닝 입장과 타이틀 복귀는 검은 화면으로 덮은 뒤 화면을 교체합니다.
입장 전에 그림과 폰트 준비를 기다리고, 전환 애니메이션이 끝난 뒤
다음 동작을 시작하므로 타이틀의 배경색이 순간적으로 비치지 않습니다.
처음 접속할 때도 캐릭터의 첫 프레임과 배경 이미지, 폰트가 준비된 후
메인 화면을 함께 표시해 캐릭터만 뒤늦게 나타나는 현상을 방지합니다.

프롤로그 뒤에는 이름 입력 → 재확인 → 기록 완료로 진행합니다.
이름은 공백을 정리한 후 최대 12자로 검사하며, 한글 조합 중 Enter는
제출하지 않습니다. 확인 전에는 저장하지 않고, 확인한 이름만 이
브라우저의 `localStorage`에 `greenstoa-player` 키로 저장합니다.
외부 서버로 전송하지 않으며 다음에 시작할 때 저장된 이름을 채워 줍니다.

기록 완료 화면에서 **이야기 시작**을 선택하면 제르디아 왕국 모험가
길드 접수대로 이어지고, **루시의 “모험가 님, 정신 차리세요~”가 첫 대사**로 나옵니다.
줄은 이미 끝난 상태이며 건국사를 다시 읽는 회상은 생략합니다. 루시는 피곤하고 시니컬하지만
주인공을 걱정하는 접수원으로, 공문을 읽거나 뜻밖의 답을 듣거나 배웅할 때
표정과 포즈가 바뀝니다. 대사 중 E를 눌러 진행합니다.

루시가 제시한 기사단의 **성역 이상 징후 사전 조사** 의뢰를 수락하거나
보류할 수 있습니다. 수락하면 의뢰서가 소지품과 의뢰 탭에 추가됩니다.
길드를 둘러본 뒤 출입문에서 E를 누르고 출발을 선택하면 루시의 배웅,
노란 머리 도적과의 마차 동행, 성역 검문, 모험가증 제시, 그린스토아 정문
도착까지 이어집니다. 검문 대화가 끝나면 정찰병 **카니아**에게 직접
다가가 E로 증명서를 제시합니다. 정문 도착 후에는 카니아와 문을 조사할 수 있습니다.
마차 동행 뒤에는 숲과 강을 감상하는 풍경 컷신이 이어집니다.
정문에서는 **카니아의 환영 대사를 모두 넘긴 후** 어머니 나무 컷신으로 전환합니다.
`assets/mother-tree.webp`의 긴 세로 원화를 화면에 가득 채워, 수관에서 줄기와
뿌리까지 32초 동안 천천히 내려 보여 줍니다. 원화의 가로세로 비율을 유지하고,
세로 화면에서도 카메라가 이동할 공간을 확보합니다. 흰 빛이 번지는 문구가 차례로
나타난 뒤 “이종족연합국 그린스토아”가 남습니다. 양피지나 그림 카드 틀은 사용하지 않습니다.
E·Enter 또는 버튼을 한 번 누르면 연출의 마지막 화면을 보여 주고, 한 번 더 누르면
성역 필드로 돌아갑니다. 연출이 끝난 뒤에는 한 번만 누르면 입장합니다.
움직임 감소 설정에서는 정지한 마지막 풍경과 제목을 바로 보여 줍니다.

조작은 WASD 이동, **왼쪽 Shift** 달리기, E 대화·조사·대사 넘기기,
C 메뉴·인벤토리입니다. 대화 중에는 이동이 멈추고, 타이핑 중 E는 문장을
완성합니다. 선택지는 W/S와 E 또는 마우스로 조작합니다. 메뉴에서는
W/S로 소지품, A/D로 탭을 고르며 E로 사용·조사합니다. C와 Esc로 닫습니다.
터치 환경에는 방향키·달리기·E 버튼과 메뉴 버튼도 표시합니다.

의뢰와 여정 사이에는 네 가지 짧은 이벤트씬이 있습니다. `JS/events.js`에서
그림·동작·효과음의 타이밍을 관리하고, `assets/event-scenes.webp`의 2열×2행
삽화에 `assets/event-props.webp`의 투명 소품을 겹쳐 사용합니다. 증서의 종이,
루시의 장갑 낀 손과 도장, 마차 바퀴, 엘프의 나무 인장을 각각 분리했습니다.
작은 화면에서는 모험가증을 같은 비율로 줄여 글씨와 인장이
잘리지 않도록 맞춥니다.

| 순간 | 연출 | 조작 |
| --- | --- | --- |
| 의뢰 수락 | 손이 도장을 들어 내려찍고, 반동·그림자·잉크 가루와 함께 인장이 남음 | 약 4초 뒤 자동 진행, E로 넘김 |
| 길드에서 출발 | 차축에 맞춘 바퀴가 가속하며 회전하고 흙먼지와 가까운 잎이 지나감 | 약 4초 뒤 자동 진행, E로 넘김 |
| 카니아에게 증명서 제시 | 증서 위에 엘프의 나무 문양이 빛나며 떠오르고 흩어진 뒤 통과 확인 | 약 4초 뒤 카니아의 대사로, E로 넘김 |
| 소지품의 낡은 지도 사용 | 제르디아에서 그린스토아까지 경로 표시 | 원하는 만큼 감상한 뒤 E·Esc로 접기 |

의뢰서는 도장이 찍히는 시점에 한 번만 등록됩니다. 연출을 빨리 넘겨도 등록을
완료하고 다음 대사로 이어지며, 인벤토리에 중복 추가되지 않습니다. 연출 중에는
이동과 메뉴를 막고, 지도는 접은 뒤 원래 인벤토리로 돌아옵니다.
움직임 감소 설정에서는 충격 흔들림과 번쩍임 없이 마지막 그림을 잠시 보여 줍니다.

소리는 `JS/audio.js`의 Web Audio 합성으로 만들며 오디오 파일이나 외부 요청이 필요 없습니다.
후드 주인공·루시·카니아·도적·길드의 다섯 인물·타이틀 안내자는 각각 다른
높낮이와 파형의 짧은 칩튠 대사음을 사용합니다. 루시는 부드러운 삼각파,
카니아는 또렷한 사각파, 도적은 거친 톱니파를 중심으로 피곤함·걱정·당혹·큰소리에도
조금씩 반응합니다. 공백과 구두점에는 울리지 않고, 빠르게 대사를 완성하거나
넘기면 남아 있는 대사음을 끊어 소리가 쌓이지 않게 합니다.
대사에는 별도의 +9dB 음량과 조금 더 분명한 발음을 적용했습니다. 말하는 동안
환경음이 잠깐 잦아들었다가 부드럽게 돌아오며, 메뉴와 충격 효과음의 음량은 유지합니다.

도장·등록 완료·종이·마차 문·바퀴·검문·발걸음·메뉴·선택·빵 먹기·성역 등장에도
각기 다른 효과음이 있습니다. 발걸음은 실제로 이동한 거리만 세므로 벽을 밀 때에는
반복 재생되지 않습니다. 실내와 마차, 숲의 환경음도 조용히 달라집니다.
기본은 소리 꺼짐이며, 소리를 켜는 사용자 동작 뒤에만 재생합니다.
설정의 소리 스위치와 음량은 대사음·효과음·환경음 전체에 적용되고,
플레이 중에도 오른쪽 위의 **♪ 켜짐/꺼짐**으로 즉시 전환할 수 있습니다.
숨겨진 탭에서는 소리를 멈추며 설정은 브라우저에 저장합니다.

길드·마차·검문소·정문은 720×480 Canvas로 그립니다. 배경과 충돌 위치,
캐릭터 이동·SD 스프라이트·대사·소지품은 `JS/game.js`에서 관리합니다.
필드 SD 도트는 44×60 네 방향·네 보행 프레임으로, 머리·옷·소품과
가느다란 윤곽을 추가해 바닥과 구별합니다. 후드 안의 얼굴은 보이지 않습니다.

`assets/map-guild.webp`, `map-carriage.webp`, `map-checkpoint.webp`,
`map-gate.webp`는 각 플레이 장소의 세밀한 픽셀 배경입니다.
충돌 위치와 접수 줄 이동, NPC의 위치도 새 그림의 가구와 길에 맞춥니다.
`assets/vista-forest.webp`, `mother-tree.webp`는 숲길과 어머니 나무 전경입니다.
타이틀·프롤로그·네 필드·숲길 배경은 자잘한 점무늬와 과도한 질감을 줄이고,
큰 색 면과 선명한 윤곽을 유지하는 방향으로 다시 정리했습니다. 필드의 가구와 길 배치는 유지합니다.
모든 새 WebP는 생성 원화와 픽셀 값이 동일한 무손실 인코딩이며,
단일 HTML에도 포함됩니다.

LD는 전원 머리부터 가슴까지의 가까운 상반신 구도로 다시 제작했습니다.
640×560 대화 초상화 Canvas에 표시하며, 투명 여백만 정리한 뒤 같은 비율로
맞춥니다. 데스크톱에서는 최대 450px 높이, 작은 화면에서는 남은 공간에 맞춰
얼굴을 크게 표시합니다. 가로·세로 크기를 함께 계산해 찌그러짐을 방지하고,
모바일 대화 중에는 목표 안내를 숨겨 초상화와 겹치지 않게 합니다.
세로형 태블릿에서는 게임 화면이 세로 공간을 채우고, 높이가 짧은 가로 화면에서는
초상화를 대화창 왼편에 배치해 선택지가 열려도 인물이 사라지지 않게 합니다.

루시는 이 길드 시퀀스에서 코트를 벗어 의자에 걸어 둔 상태입니다.
LD와 필드 SD 모두 **긴 흰 블라우스·보라색 리본·어두운 장갑** 차림으로
맞췄습니다. 머리는 곱슬이나 큰 컬 없이 길게 흐르는 형태입니다.
피곤하고 시니컬하지만 정이 많은 성격은 표정과 기존 대사에 반영합니다.

설명, 모험가증 제시 때에는 확인하는 모습, 정문에서는 환영하는 모습으로
전환합니다. 당황한 표정은 이후 장면에도 사용할 수 있습니다.
카니아의 연녹색 머리·은빛 어깨 갑옷·에메랄드 장식, 도적의 반쯤 민 머리·
노란 앞머리·검은 가시 갑옷은 레퍼런스를 따릅니다. 감정 키와 시트 연결은
`JS/game.js`의 `portraitFor`에서 관리합니다. 기존 LD 파일은 새 시트로 교체했습니다.

말을 시작하거나 감정이 바뀔 때 초상화가 2~7px 정도 짧게 튀고,
긴 대사 중에는 작은 반응을 최대 세 번 더합니다. 항상 떠다니는 움직임은 없으며,
대화가 끝나면 움직임도 멈춥니다. 초상화는 고정된 마스크 안에서 움직이고
아래에 12px 여분을 두어, 몸이 올라가도 대화창 위에 배경 틈이 생기지 않습니다.
마차 흔들림에도 배경 끝부분을 연장해 화면 가장자리가 비지 않게 합니다.
화면 움직임을 끄거나 시스템 움직임 감소를
설정하면 초상화 반응·꽃가루·카메라 이동을 모두 정지합니다.

길드의 엑스트라 다섯 명과 게시판·기록장·출입문도 조사할 수 있습니다.
모험가증은 처음부터 소지하고, 마른 빵은 실제 소모되며 체력을 회복합니다.
플레이 진행은 현재 실행 중인 세션에 보관되고, 타이틀에서 다시 시작하면
길드의 루시 대사부터 진행합니다. 이름과 화면·소리 설정은 브라우저에 저장됩니다.

# 이종족연합국 그린스토아

정적 HTML로 만든 도트풍 타이틀 화면입니다. `index.html`에 배경 이미지,
스타일, 동작 코드가 모두 포함되어 있어 별도 설치나 빌드 없이 열 수 있습니다.

로컬 서버로 확인하려면 저장소에서 `python3 -m http.server 8000`을 실행하세요.

`CSS/main.css`, `JS/main.js`, 배경 이미지를 수정한 뒤에는
`python3 scripts/build-standalone.py`를 실행해 `index.html`에 반영하세요.
문구와 화면 구조는 `templates/index.html`에서 수정한 다음 같은 명령으로
단일 파일을 생성합니다. 생성된 `index.html`에는 폰트까지 모두 포함됩니다.

UI에는 Galmuri 2.40.3 한글 픽셀 폰트를 사용합니다. 라이선스는
`assets/fonts/LICENSE.txt`와 생성 HTML에 포함되어 있습니다.

캐릭터는 `assets/greenstoa-elf-idle.png` 왼쪽 원화를 고정된 기준으로
사용합니다. 원화를 기준으로 머리카락·망토·호흡 포즈를 고정된 도트
프레임으로 미리 만든 뒤 10fps로 교체합니다. 눈은 열림·반쯤 감김·감김의
세 단계로 표시하며 색상을 페이드하지 않습니다. 오른쪽 원화는 눈을 감는
작은 영역에만 사용하고 얼굴 전체를 교체하지 않습니다.
6.4초 주기가 같은 원화로 이어집니다.
어깨와 상체에는 3.2초 주기의 작은 호흡 움직임을 적용합니다. 원화 기준
최대 2픽셀만 올라가며 얼굴과 하체 쪽으로 갈수록 움직임이 줄어듭니다.
옵션이나 시스템의 움직임 감소 설정으로 정지할 수 있습니다.

캐릭터의 보이는 부분을 클릭하면 클릭한 위치에 사각 말풍선이 열립니다.
다시 클릭하거나 말풍선의 다음 버튼을 누르면 8개의 임시 대사를 순서대로
보여줍니다. 대사는 `JS/main.js`의 `dialogues`에서 수정할 수 있습니다.
캐릭터에 키보드 초점을 두고 Enter 또는 Space로 대화할 수도 있습니다.
말풍선은 닫기 버튼, Escape 또는 바깥 클릭으로 닫습니다.

마우스 커서는 `assets/cursors/`의 32px 픽셀 만년필이며 펜촉이 클릭
위치입니다. 버튼 위에서는 작은 빛 표시가 붙고 버튼이 살짝 떠오릅니다.
클릭할 때는 클릭 위치에서 밝은 도트가 퍼지며 버튼은 짧게 눌렸다 튀어
오릅니다. 효과는 설정 창 위에도 표시되며 터치와 키보드 버튼 조작도
지원합니다. 화면 움직임을 끄거나 시스템의 움직임 감소를 설정하면
추가 애니메이션도 정지합니다. 커서 SVG 역시 단일 HTML에 포함됩니다.

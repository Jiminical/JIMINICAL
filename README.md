# 이종족연합국 그린스토아

정적 HTML로 만든 도트풍 타이틀·프롤로그·길드 플레이 화면입니다. `index.html`에 배경 이미지,
스타일, 동작 코드가 모두 포함되어 있어 별도 설치나 빌드 없이 열 수 있습니다.

로컬 서버로 확인하려면 저장소에서 `python3 -m http.server 8000`을 실행하세요.

`CSS/main.css`, `CSS/game.css`, `JS/main.js`, `JS/story.js`, `JS/game.js`, 이미지를 수정한 뒤에는
`python3 scripts/build-standalone.py`를 실행해 `index.html`에 반영하세요.
문구와 화면 구조는 `templates/index.html`에서 수정한 다음 같은 명령으로
단일 파일을 생성합니다. 생성된 `index.html`에는 폰트까지 모두 포함됩니다.

UI에는 Galmuri 2.40.3 한글 픽셀 폰트를 사용합니다. 라이선스는
`assets/fonts/LICENSE.txt`와 생성 HTML에 포함되어 있습니다.

캐릭터는 `assets/greenstoa-elf-idle.png` 왼쪽 원화를 고정된 기준으로
사용합니다. 원화를 기준으로 머리카락·망토·호흡 포즈를 고정된 도트
프레임으로 미리 만든 뒤 10fps로 교체합니다. 눈은 열림·반쯤 감김·감김의
세 단계로 표시하며 색상을 페이드하지 않습니다. 오른쪽 원화는 눈을 감는
작은 영역에만 사용하고 얼굴 전체를 교체하지 않습니다.
6.4초 주기가 같은 원화로 이어집니다.
어깨와 상체에는 3.2초 주기의 작은 호흡 움직임을 적용합니다. 원화 기준
최대 2픽셀만 올라가며 얼굴과 하체 쪽으로 갈수록 움직임이 줄어듭니다.
옵션이나 시스템의 움직임 감소 설정으로 정지할 수 있습니다.

캐릭터의 보이는 부분을 클릭하면 클릭한 위치에 사각 말풍선이 열립니다.
다시 클릭하거나 말풍선의 다음 버튼을 누르면 8개의 임시 대사를 순서대로
보여줍니다. 대사는 `JS/main.js`의 `dialogues`에서 수정할 수 있습니다.
캐릭터에 키보드 초점을 두고 Enter 또는 Space로 대화할 수도 있습니다.
말풍선은 닫기 버튼, Escape 또는 바깥 클릭으로 닫습니다.

마우스 커서는 `assets/cursors/`의 32px 픽셀 만년필이며 펜촉이 클릭
위치입니다. 버튼 위에서는 작은 빛 표시가 붙고 버튼이 살짝 떠오릅니다.
클릭할 때는 클릭 위치에서 밝은 도트가 퍼지며 버튼은 짧게 눌렸다 튀어
오릅니다. 효과는 설정 창 위에도 표시되며 터치와 키보드 버튼 조작도
지원합니다. 화면 움직임을 끄거나 시스템의 움직임 감소를 설정하면
추가 애니메이션도 정지합니다. 커서 SVG 역시 단일 HTML에 포함됩니다.

시작하기를 누르면 여섯 장면의 양피지 프롤로그가 이어집니다.
내레이션과 삽화 배치는 `JS/story.js`의 `scenes`에서, 그림은
`assets/greenstoa-prologue.png`의 2열×3행 가로 삽화 시트에서 관리합니다.
검은 여백 가운데 가로 삽화를 배치하고 바로 아래에 내레이션이
한 글자씩 나타납니다. 삽화는 원본의 9:4 비율과 전체 구도를 유지하며,
화면에 맞춰 같은 배율로 축소합니다. 쉼표와 문장 끝에서 잠시 쉬며, 줄바꿈 위치는
타이핑 중에도 고정됩니다. 다음 버튼을 한 번 누르면 문장 전체를 보이고,
한 번 더 누르면 다음 장면으로 넘어갑니다. 자동 넘김은 타이핑이 끝난
후 읽을 시간을 두고 진행되며 끌 수도 있습니다. 건너뛰기는 이름
입력으로 연결됩니다. 화면 움직임 감소 설정에서는 페이드와 타이핑을
생략하고 문장 전체를 표시합니다.

오프닝 입장과 타이틀 복귀는 검은 화면으로 덮은 뒤 화면을 교체합니다.
입장 전에 그림과 폰트 준비를 기다리고, 전환 애니메이션이 끝난 뒤
다음 동작을 시작하므로 타이틀의 배경색이 순간적으로 비치지 않습니다.
처음 접속할 때도 캐릭터의 첫 프레임과 배경 이미지, 폰트가 준비된 후
메인 화면을 함께 표시해 캐릭터만 뒤늦게 나타나는 현상을 방지합니다.

프롤로그 뒤에는 이름 입력 → 재확인 → 기록 완료로 진행합니다.
이름은 공백을 정리한 후 최대 12자로 검사하며, 한글 조합 중 Enter는
제출하지 않습니다. 확인 전에는 저장하지 않고, 확인한 이름만 이
브라우저의 `localStorage`에 `greenstoa-player` 키로 저장합니다.
외부 서버로 전송하지 않으며 다음에 시작할 때 저장된 이름을 채워 줍니다.

기록 완료 화면에서 **이야기 시작**을 선택하면 제르디아 왕국 모험가
길드로 이어집니다. 주인공이 그린스토아의 건국을 떠올리는 동안 접수 줄이
빠지고, 루시의 부름에 정신을 차립니다. 루시는 피곤하고 시니컬하지만
주인공을 걱정하는 접수원으로, 공문을 읽거나 뜻밖의 답을 듣거나 배웅할 때
표정과 포즈가 바뀝니다. 대사 중 E를 눌러 진행합니다.

루시가 제시한 기사단의 **성역 이상 징후 사전 조사** 의뢰를 수락하거나
보류할 수 있습니다. 수락하면 의뢰서가 소지품과 의뢰 탭에 추가됩니다.
길드를 둘러본 뒤 출입문에서 E를 누르고 출발을 선택하면 루시의 배웅,
노란 머리 도적과의 마차 동행, 성역 검문, 모험가증 제시, 그린스토아 정문
도착까지 이어집니다. 검문 대화가 끝나면 정찰병에게 직접 다가가 E로
증명서를 제시합니다. 정문 도착 후에는 정찰병과 문을 조사할 수 있습니다.

조작은 WASD 이동, **왼쪽 Shift** 달리기, E 대화·조사·대사 넘기기,
C 메뉴·인벤토리입니다. 대화 중에는 이동이 멈추고, 타이핑 중 E는 문장을
완성합니다. 선택지는 W/S와 E 또는 마우스로 조작합니다. 메뉴에서는
W/S로 소지품, A/D로 탭을 고르며 E로 사용·조사합니다. C와 Esc로 닫습니다.
터치 환경에는 방향키·달리기·E 버튼과 메뉴 버튼도 표시합니다.

길드·마차·검문소·정문은 720×480 Canvas로 그립니다. 배경과 충돌 위치,
캐릭터 이동·SD 스프라이트·대사·소지품은 `JS/game.js`에서 관리합니다.
필드 SD 도트는 44×60 네 방향·네 보행 프레임으로, 머리·옷·소품과
가느다란 윤곽을 추가해 바닥과 구별합니다. 후드 안의 얼굴은 보이지 않습니다.

`assets/lucy-portrait.png`는 루시의 기본 LD 초상화,
`assets/lucy-expressions.png`는 공문 읽기·당혹·걱정하는 세 포즈입니다.
`assets/guild-portraits.png`는 위쪽부터 주인공·브란·미아·나라,
토빈·레온·도적·정찰병 순서의 4열×2행 LD 초상화입니다.
루시의 픽셀 선화에 맞춘 그림으로 교체했고, 실제 시트의 빈 경계를 사용해
옆 인물이 섞이거나 어깨가 잘리지 않도록 전체 폭을 비율대로 맞춥니다.
이미지의 투명한 여백만 제외해 초상화를 대화창 위에 붙입니다.

길드의 엑스트라 다섯 명과 게시판·기록장·출입문도 조사할 수 있습니다.
모험가증은 처음부터 소지하고, 마른 빵은 실제 소모되며 체력을 회복합니다.
플레이 진행은 현재 실행 중인 세션에 보관되고, 타이틀에서 다시 시작하면
길드의 회상부터 진행합니다. 이름과 화면·소리 설정은 브라우저에 저장됩니다.
